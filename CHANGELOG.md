# Changelog

All notable changes to `@mbarde/volto-fullcalendar-block` will be documented in this file.

## [1.1.0] - 2026-10-24

### Bug Fixes & Accessibility
- **Volto 19 Compatibility:** Updated `peerDependencies` to support `@plone/volto` 17, 18, and 19 (`>=17.0.0 || >=18.0.0-alpha.0 || >=19.0.0-alpha.0`).
- **ADA & Semantic Links:** Resolved ADA accessibility issues across calendar events and anchors by rendering semantic, accessible link elements.

## [1.0.1]

### Initial Release
- FullCalendar integration for Plone Volto with daygrid, timegrid, and list views.
